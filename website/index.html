Knowledge Base

Frequently Asked Questions

Everything you need to know about setup, pairing, and security.

How does remote pairing work without opening router ports?
The app uses an asynchronous encrypted signaling channel over ntfy. When paired, both devices communicate through a private, random topic name. All payloads are encrypted locally on the device with AES-256 before transmission using your shared secret code. When on the same local Wi-Fi, the app automatically switches to direct local WebSockets.
How does the Calculator Panic Decoy work?
Tapping the panic shield icon in the header (or pressing the panic hotkey) instantly replaces the entire application interface with a real, fully functioning arithmetic calculator. To exit disguise mode, type 7777 and hit =, or long-press the calculator top title bar.
Can multiple Directors pair with one Submissive?
Yes! The app features Strict Director Command Isolation. When multiple Directors pair with the same player, each Director only sees and reviews the directives that they personally dispatched. Other Directors' orders and solo routines are completely isolated and hidden.
Are there any subscriptions?
Advanced features such as scheduled tasks and questlines are available through Patreon, with more features coming to supporters soon. The vast majority of features are free!
